# Handwriting glyphs

`src/glyphs.data.ts` is generated by `scripts/build-glyphs.mjs` from:

- **EMS Allure** (Latin letters, digits, punctuation): a single-stroke version of Allura by
  Sheldon B. Michaels, converted to an SVG font by Windell H. Oskay (Evil Mad Scientist).
  SIL Open Font License 1.1; see `OFL.txt`.
- **Hershey fonts** (Greek letters and math symbols), originally by Dr. A. V. Hershey at the
  U.S. National Bureau of Standards, as packaged in `hersheytext` (MIT, James T).

Rebuild with `pnpm --filter @writey/inkscript glyphs`.
